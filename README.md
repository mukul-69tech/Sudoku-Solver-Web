# Sudoku Solver in C++

A console-based 9x9 Sudoku Solver built using C++. This project uses the Backtracking Algorithm and Recursion to solve Sudoku puzzles efficiently.

## Features

- Solves standard 9x9 Sudoku puzzles
- Uses Backtracking and Recursion
- Validates row, column, and 3x3 subgrid constraints
- Handles invalid and unsolvable puzzles
- Simple CLI-based interface

## Tech Stack

- C++
- Recursion
- Backtracking
- STL
- 2D Arrays

## How to Run

### Compile

```bash
g++ main.cpp -o sudoku
